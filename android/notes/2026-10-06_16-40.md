# 2026-10-06 16:40 — Book RAG for Android 0.1.0, and the logo on the three web apps

## Summary
- New Android app in `android/` covering the main web app (ask) and the verify app. Not admin.
- Project setup (Gradle, signing, manifest, markdown renderer) was copied from the Finance RAG app.
  The code is organised differently: one vertical slice per feature, see `README.md`.
- `logo.png` (repository root) was snapped to two exact colours (`#2563EB`, `#DBEAFE`) and is the
  master for the Android icon and for `public/` in `frontend`, `admin_app` and `verify_app`.
- Web apps deployed as `v0.1.3` (favicon, login page, sidebar mark). No API change, no migration.

## Key decisions
- **Colours**: the app's ground is neutral paper (light) or ink (dark), following the phone. Blue is
  only for the main action, your own messages and selected chips. The icon keeps the logo's blue.
- **Citations**: the answer's `<CITATION>` tags become `[n]` markers with tappable references under
  the answer, since a phone has no room for a side panel.
- **Verify progress** is polling the document every 2 seconds, exactly as the web app does. A second
  opinion is followed by the claim ids the API returns, because it never changes the document status.
- **No refresh token** exists in this API, so a 401 ends the session. No retry logic.
- **Same release signing key** as Finance RAG.
